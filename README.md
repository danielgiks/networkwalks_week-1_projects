Networkwalks Cybersecurity Internship – Week 1

 📁 1. Lab Setup (VirtualBox)

For this project, I successfully built a virtual cybersecurity lab environment using **Oracle VirtualBox**. The following tasks were completed:

-Network Configuration:** Created a NAT Network with the subnet `10.0.0.0/24` to enable network communication within the virtual environment.
-Kali Linux Configuration:** Imported and configured Kali Linux, assigning it a static IP address of `10.0.0.3`.
-Connectivity Test:** Verified internet connectivity from the virtual machine by successfully pinging Google's public DNS server (`8.8.8.8`).
-Shared Folders:** Enabled a shared folder between the host machine and Kali Linux for easy file transfer.
- Snapshot:** Created a virtual machine snapshot named **Lab Setup Complete** to preserve the working environment for future practical exercises.
